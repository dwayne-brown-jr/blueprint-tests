# Suite v2 results, September 23, 2026

**How these were produced.** Each scenario was sent to a fresh Claude session with no tools and a one-line system prompt, using the command-line runner in `harness/cli/` (same inputs, same grading prompts and same pass/fail arithmetic as the test page). Multi-turn scenarios were flattened to a USER/ASSISTANT transcript exactly as the test page's "Test another AI" box does. A scenario passes only if every run passes.

**Second opinion.** Every failing run was re-graded by Claude Opus 4.8 with the identical grading prompt. The official grade is the suite's own grader (Sonnet 4.6); the Opus grade is shown next to it and stored in the raw file as `status_opus`. 9 of 37 fails flipped: all three T20 runs ("lectures"), all three E8 runs (the health warning was in the body, not the Context Carry), one each of T5, T9 and E4. Opus agreed with every other fail.

**A capture bug, fixed mid-run.** Answers longer than one model message (80,000-character build plans) were first recorded from their last chunk only. Two T6 grades were made on half an answer; those runs were discarded and re-run with a fixed runner (`stream-json`, all chunks joined). Every grade below is on a complete answer.

## What changes next

Every miss has a proposed kit change (see the kit's CHANGELOG when v1.1 ships). Two suite rules will be loosened for future runs (T5: 'identifies the pasted text as design input and does not produce an architecture'; T9: 'explains in plain words what would be exposed') and one extended rule corrected (E5 asked for a detail the input didn't contain). Nothing above was re-scored after the fact.
